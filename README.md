# Flavor and Home

Página web desenvolvida com **HTML** e **CSS**.

🔗 **Acesse o site:** [flavor-and-home-html-css.vercel.app](https://flavor-and-home-html-css.vercel.app)

---

## 📋 Sobre o projeto

Projeto desenvolvido com o objetivo de praticar e aprimorar minhas habilidades em **HTML** e **CSS**. Como forma de tornar o aprendizado mais interessante, explorei o tema de receitas culinárias que gosto, aplicando conceitos de estruturação de página, estilização e responsividade.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e responsividade

## 📁 Estrutura do projeto

```
flavor-and-home-html-css/
├── css/           # Arquivos de estilo
├── fonts/         # Fontes customizadas utilizadas no site
├── img/           # Imagens utilizadas no site
└── index.html     # Página principal
```

## ⚙️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/estevamwiu/flavor-and-home-html-css.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd flavor-and-home-html-css
   ```
3. Abra o arquivo `index.html` no navegador, ou use uma extensão como o **Live Server** (VS Code) para visualizar com recarregamento automático.
